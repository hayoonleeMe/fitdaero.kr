# Frontend 작업 지침

## 기술과 구조

- React, TypeScript, Vite, Tailwind CSS를 사용한다.
- 화면 컴포넌트는 `src/pages/`, 재사용 UI는 `src/components/`, HTTP 호출과 API 타입은 `src/api/`에 둔다.
- 컴포넌트 파일명은 `PascalCase.tsx`로, 한 화면에서만 쓰는 컴포넌트는 해당 화면 가까이에 둔다.
- API 응답 타입은 백엔드 계약과 일치하게 작성하고, 컴포넌트에서 직접 `fetch`하지 않는다.

## UI 원칙

- 모바일 우선 반응형으로 만들고, 휴대폰과 데스크톱에서 모두 사용 가능해야 한다.
- Tailwind 기본 유틸리티를 사용한다. 별도 UI 라이브러리나 전역 상태관리 라이브러리는 추가하지 않는다.
- 버튼, 입력, 선택 요소는 가능한 네이티브 HTML 요소를 사용하고, label·오류 메시지·키보드 포커스를 제공한다.
- 디자인은 흰 배경과 파란색 계열을 기본으로 하며, 장식보다 입력과 추천 결과의 정보 위계를 우선한다.

## 검증

- 변경 후 `npm run lint`와 `npm run build`를 실행한다.
- 분기 또는 데이터 변환 로직을 추가하면 가장 작은 단위 테스트를 함께 추가한다.
