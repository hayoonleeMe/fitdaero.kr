# FitDaero MVP PRD

## 1. 제품 정의

FitDaero는 사용자의 체력 상태와 생활조건에 맞는 실제 공공 운동 프로그램을 추천하는 웹 서비스다.

> 무엇을 운동해야 할지에서 끝나지 않고, 참여 가능한 공공 프로그램까지 연결한다.

국민체력100은 서비스명이나 간편 분석의 기준이 아니다. 국민체력100 측정 결과가 있는 사용자가 더 정확한 체력 비교를 받을 수 있도록 하는 정밀 분석의 데이터 출처로 활용한다.

## 2. 문제와 MVP 목표

### 문제

- 운동을 시작하려는 사람은 자신의 목표와 현재 생활패턴에 맞는 종목을 고르기 어렵다.
- 체력 측정 결과가 있어도 실제로 참여 가능한 공공 프로그램을 다시 찾아야 한다.

### MVP 목표

1. 측정 결과가 없는 사용자도 간편 분석으로 프로그램을 추천받는다.
2. 국민체력100 결과가 있는 성인 사용자는 체력 요소 비교를 반영한 정밀 추천을 받는다.
3. 지역과 가능한 요일을 고려해 실제 참여 가능성이 높은 프로그램을 먼저 보여준다.

### 성공 기준

- 데모에서 `분석 방식 선택 → 조건 입력 → 추천 이유가 있는 프로그램 결과`를 완료한다.
- 간편 분석은 응답 기반 추천임을, 정밀 분석은 공개 측정 데이터 기반 비교임을 구분해 보여준다.
- 모든 추천 결과에 사용 데이터 출처와 적재 버전을 확인할 수 있다.

## 3. 대상 사용자와 분석 방식

### 대상 사용자

운동을 시작하거나 재개하려는 성인 중 공공체육시설 프로그램을 찾는 사람이다. 정밀 분석은 현재 공개 데이터의 비교 범위에 맞춰 만 19~64세만 제공한다.

### 간편 분석

국민체력100 측정 결과가 없는 사용자를 위한 경로다.

| 입력        | 설명                                       |
| --------- | ---------------------------------------- |
| 운동 목표     | 근력, 근지구력, 유연성, 심폐지구력, 체중관리, 스트레스 해소 중 하나 |
| 주간 활동량    | 숨이 찰 정도의 운동 빈도                           |
| 운동 경험     | 초보, 중단 후 재개, 규칙적 운동 중 하나                 |
| 선호·비선호 종목 | 복수 선택 가능                                 |
| 지역        | 시도 필수, 시군구 선택                            |
| 가능한 요일    | 하나 이상 선택                                 |

결과는 활동·목표·선호를 바탕으로 한 추천이다. 체력 수준, 의학적 판단, 국민체력100 백분위는 표시하지 않는다.

### 정밀 분석

국민체력100 측정 결과가 있는 성인 사용자를 위한 경로다.

| 입력                 | 설명                                 |
| ------------------ | ---------------------------------- |
| 나이·비교 기준 성별        | 19~64세, 원본 비교 그룹과 같은 `F` 또는 `M`    |
| 체력 측정값             | 상대악력, 앉아윗몸앞으로굽히기, 교차윗몸일으키기 중 하나 이상 |
| 운동 목표·선호·지역·가능한 요일 | 간편 분석과 같은 추천 조건                    |

입력된 체력 항목은 2022년 이후 국민체력100 공개 측정결과 API의 동일 성별·10세 단위 연령대 표본과 비교해 `낮음 / 보통 / 높음`으로만 표시한다. 이는 공개 데이터 분포 비교이며 국민체력100 공식 인증 등급이나 의료적 판단이 아니다.

### 공통 흐름

```text
분석 방식 선택
        ↓
목표·생활조건 또는 체력 결과 입력
        ↓
지역·요일에 맞는 프로그램 후보 검색
        ↓
분석 근거와 함께 상위 5개 프로그램 추천
```

정밀 분석을 마친 뒤 더 정확한 공식 측정을 원하는 사용자에게는 [국민체력100 체력인증센터 찾기](https://nfa.kspo.or.kr/intro/centerList.kspo) 링크만 제공한다. 센터 위치를 적재하거나 가까운 센터를 계산하지 않는다.

## 4. 추천 결과

각 결과에는 다음을 표시한다.

- 프로그램명, 시설명, 주소, 홈페이지
- 프로그램 기간, 개설 요일, 공개 가격과 가격 유형
- 검색 범위: 선택 시군구 또는 시도 확장
- 추천 사유: 목표·체력 요소·선호 종목·요일·성인 대상 여부

시군구에서 후보가 없을 때만 같은 시도로 검색 범위를 확장한다. 프로그램 요일이 사용자 가능 요일과 하루 이상 겹치면 후보로 포함하고, 공통 요일이 많을수록 더 높은 점수를 준다.

세부 점수·종목군·동점 규칙은 [추천 명세](recommendation.md)를 따른다.

## 5. 활용 데이터

| 데이터                                                                                                                         | MVP 용도                  | 사용 방식             |
| --------------------------------------------------------------------------------------------------------------------------- | ----------------------- | ----------------- |
| [공공체육시설 프로그램 정보](https://www.bigdata-culture.kr/bigdata/user/data_market/detail.do?id=c3b8fb69-307d-4ae7-ab42-d0314c89ef47) | 시설·프로그램·지역·요일·기간·가격     | 운영자가 서버 볼륨에 둔 파일을 시작 적재 옵션으로 적재 |
| [국민체력100 체력인증센터 측정결과 API](https://www.data.go.kr/data/15108938/openapi.do)                                                  | 정밀 분석용 성인·성별·연령대 체력 기준값 | 시작 적재 옵션으로 API 집계 |

정밀 분석용 API는 2022년 이후 성인 여성·남성 데이터만 사용한다. 응답의 `pres_note` 등 운동처방 원문은 추천 규칙에 사용하거나 저장하지 않는다. 원본 처리와 개인정보 최소화는 [적재 명세](data-import.md)를 따른다.

정밀 분석은 가장 최근에 완료된 체력 API 적재본의 비교 기준만 사용한다.

기본 실행은 `APP_IMPORT_ON_STARTUP=false`이며, 기존 적재 데이터로 추천 API만 제공한다. `true`일 때만 서버 볼륨의 프로그램 CSV와 체력 API를 서로 독립적으로 시작 적재한다. 적재가 실패해도 이전 완료 데이터는 유지한다. 완료된 프로그램 데이터가 없으면 추천 결과는 비어 있고, 완료된 체력 기준이 없으면 정밀 분석은 기준값 없음 오류를 반환한다.

## 6. 범위 밖

- 회원가입·로그인·사용자 입력 및 추천 이력 저장
- 실시간 예약, 정원 확인, 결제
- 가격 필터·가격 점수·월 예산 환산
- 시간대 필터·거리 계산·지도·길찾기
- 체력인증센터 위치 적재·가까운 센터 계산
- 의료 진단, 치료, 운동 처방
- 프로그램 포털 로그인 세션을 사용한 HTTP 자동 다운로드
- 자동 다운로드 스케줄러와 일일 외부 동기화

## 7. 구현 경계

- 단일 Spring Boot 애플리케이션과 MySQL을 사용한다.
- 추천 API와 시작 적재는 같은 애플리케이션 안에 둔다.
- 사용자 입력은 요청 처리에만 사용하며 DB에 저장하지 않는다.
- API 계약은 [API 명세](api.md), 논리 모델은 [ERD](erd.md)를 따른다.
