# FitDaero MVP 추천 명세

## 1. 종목군과 연관 요소

프로그램명과 원본 프로그램 유형을 함께 사용해 아래 종목군으로 정규화한다. 하나의 프로그램은 하나의 종목군만 가진다. 텍스트는 앞뒤 공백 제거, HTML `<br>`의 공백 치환, 연속 공백 축소 후 비교한다.

| 종목군 | 주요 체력 요소·목표 |
| --- | --- |
| `SWIMMING_AQUA` | 심폐지구력, 근력, 유연성, 체중관리 |
| `FITNESS_STRENGTH` | 근력, 근지구력, 체중관리 |
| `YOGA_PILATES` | 유연성, 근력, 스트레스 해소 |
| `CARDIO` | 심폐지구력, 체중관리 |
| `DANCE_AEROBIC` | 심폐지구력, 유연성, 체중관리, 스트레스 해소 |
| `RACKET_SPORTS` | 심폐지구력, 근력, 스트레스 해소 |
| `BALL_SPORTS` | 심폐지구력, 근력, 스트레스 해소 |
| `MARTIAL_ARTS` | 근력, 근지구력, 유연성, 스트레스 해소 |
| `CLIMBING` | 근력, 근지구력, 유연성 |
| `GOLF` | 유연성, 스트레스 해소 |
| `OTHER` | 개인화 점수 없음 |

종목 분류는 `PROGRM_TY_NM`을 먼저, 매칭되지 않을 때 `PROGRM_NM`을 사용한다. 각 텍스트에서는 가장 왼쪽에 등장한 키워드를 선택하며, 같은 위치면 아래 표의 순서를 적용한다.

| 종목군 | 키워드 |
| --- | --- |
| `SWIMMING_AQUA` | 수영, 아쿠아 |
| `FITNESS_STRENGTH` | 헬스, 휘트니스, 피트니스, 웨이트, 근력, 보디빌딩 |
| `YOGA_PILATES` | 요가, 필라테스 |
| `CARDIO` | 걷기, 러닝, 달리기, 마라톤, 사이클, 자전거 |
| `DANCE_AEROBIC` | 댄스, 에어로빅, 줌바, 라인댄스 |
| `RACKET_SPORTS` | 테니스, 배드민턴, 탁구, 스쿼시, 라켓볼 |
| `BALL_SPORTS` | 축구, 풋살, 농구, 배구, 야구, 핸드볼 |
| `MARTIAL_ARTS` | 태권도, 합기도, 유도, 검도, 복싱, 주짓수, 킥복싱, 무에타이 |
| `CLIMBING` | 클라이밍 |
| `GOLF` | 골프 |

`OTHER`는 정규화된 후보가 5건보다 적을 때만 보조 후보로 사용한다.

## 2. 후보 선정

1. `ends_on >= 요청일`인 프로그램만 사용한다.
2. 선택 시군구에서 후보를 찾는다. 결과가 없을 때만 같은 시도의 모든 시군구로 확장한다.
3. 대상이 `CHILD_ONLY`인 프로그램은 제외한다.
4. 프로그램의 `weekday_mask`와 사용자 `weekdays`의 교집합이 하나 이상이어야 한다.
5. 비선호 종목군은 제외한다.
6. 요일을 해석하지 못한 행은 제외한다. 종목군이 `OTHER`인 행은 정규화된 후보가 5건보다 적을 때만 보조 후보로 고려한다.

## 3. 요일 적합도

```text
공통 요일 수 = 프로그램 개설 요일 ∩ 사용자 가능 요일
요일 적합도 = 배점 × 공통 요일 수 / 프로그램 개설 요일 수
```

하루라도 겹치면 후보에 포함한다. 프로그램의 모든 개설 요일에 참여 가능하면 만점이며, 공통 요일이 적을수록 점수가 낮아져 결과 뒤로 정렬된다.

## 4. 간편 분석 점수

| 기준 | 배점 | 규칙 |
| --- | ---: | --- |
| 운동 목표 적합 | 40 | 종목군이 선택 목표와 연관되면 전부 부여 |
| 활동량·초보 적합 | 15 | `NONE`/`LOW` 또는 `BEGINNER`일 때, 정규화한 프로그램 유형·이름에 `입문`, `초급`, `기초`, `초보` 중 하나가 있으면 부여 |
| 선호 종목 적합 | 15 | 선호 종목군이면 전부 부여 |
| 성인 대상 명확성 | 5 | `ADULT_EXPLICIT` 5점, `ADULT_POSSIBLE` 3점, `UNKNOWN` 0점 |
| 요일 적합도 | 25 | 위 공식 적용 |
| 합계 | 100 | |

## 5. 정밀 분석 점수

가장 최근 완료된 체력 API 적재본에서, 요청 나이에 해당하는 동일 성별·10세 단위 연령대 기준의 25 분위 미만인 체력 요소를 낮은 체력 요소로 본다. 낮은 요소가 없으면 해당 점수는 0점이며 운동 목표 점수가 추천의 중심이 된다.

| 기준 | 배점 | 규칙 |
| --- | ---: | --- |
| 낮은 체력 요소 적합 | 40 | 낮은 요소와 연관된 종목군이면 전부 부여 |
| 운동 목표 적합 | 25 | 종목군이 선택 목표와 연관되면 전부 부여 |
| 선호 종목 적합 | 15 | 선호 종목군이면 전부 부여 |
| 성인 대상 명확성 | 5 | 간편 분석과 같은 규칙 |
| 요일 적합도 | 15 | 위 공식 적용 |
| 합계 | 100 | |

체력 요소 연결은 `RELATIVE_GRIP → 근력`, `SIT_AND_REACH → 유연성`, `CROSS_SIT_UP → 근지구력`이다.

## 6. 정렬과 추천 사유

최종 점수 내림차순으로 정렬한다. 동점이면 다음 순서를 적용한다.

1. 선택 시군구 결과
2. 성인 대상 명확성
3. 공통 요일 수
4. 종료일이 더 늦은 프로그램
5. 프로그램명 오름차순

결과에는 점수를 구성한 항목만 자연어 사유로 표시한다. 공개 가격은 표시할 뿐 점수·필터에 사용하지 않는다.
